# ⭐ Projeto em destaque

## MUAC

O **MUAC** é meu principal projeto autoral.

É uma plataforma editorial e criativa que mistura:

**música · audiovisual · fotografia · textos · arte · moda · experiências**

O projeto nasceu como uma forma de transformar uma ideia criativa em um produto digital real.

Tecnicamente, o MUAC envolve:

* Next.js
* TypeScript
* React
* Notion API
* Cloudflare Workers
* Cloudflare D1
* OpenNext
* APIs próprias
* Analytics
* Dashboard administrativo
* Autenticação e proteção de acesso
* Segurança
* Deploy serverless

Também utilizo **inteligência artificial durante o processo de desenvolvimento**, principalmente para pesquisa, prototipação, resolução de problemas, revisão de código e exploração de soluções.
